# 轮回答卷

## 项目描述
**轮回答卷**是一款基于 C++ 标准库开发的控制台文本选择冒险游戏，玩家将扮演一名即将面临中考的学生。从一个普通的早晨开始，你将面对一系列关键决策，每一个选择都可能影响故事的走向。游戏以简洁的文字叙述和分支选项为核心，探索日常生活中的抉择与后果。适合喜欢轻松互动故事的玩家体验，当前版本为预览版，部分剧情仍在开发中。

当前版本：26w40a

## 核心特性
- 纯控制台交互
- 多结局设计
- 自动日志输出
- 输入验证机制
- 简易功能菜单

## 运行要求
- 操作系统：Windows（暂不兼容 Linux/macOS）
- 编译环境：C++17 及以上的编译器（如 MinGW-g++、MSVC）
- 依赖：仅使用 C++ 标准库，无第三方依赖

## 编译步骤
将 `main.cpp`，`function_1.h`，`set_1.h`，`changeLog.md ` 放在同一目录，打开终端执行：
```bash
# MinGW-g++ 编译（推荐）
g++ main.cpp -std=c++17 -o main.exe

# MSVC 编译（可选）
cl main.cpp /Fe:main.exe
